# ggplot extensions

The following are extensions you can choose to use for your project. If you make
a chart using one of these extensions, it will count for 2 of your required 3
charts. Some of these are specialized plot types, so don't use them if they're
not appropriate for your data and audience.

- [ggraph](https://github.com/thomasp85/ggraph), really only applicable to the
  spending data unless you BYO hierarchical or network data
- [treemapify](https://github.com/wilkox/treemapify), also only applicable for
  hierarchical data
- [ggalluvial](https://github.com/corybrunson/ggalluvial)
- [ggridges](https://cran.r-project.org/web/packages/ggridges/vignettes/introduction.html)
- [ggdist](https://mjskay.github.io/ggdist)
- [ggmosaic](https://github.com/haleyjeppson/ggmosaic)
- [ggally](https://ggobi.github.io/ggally/)
- [waffle](https://github.com/hrbrmstr/waffle), CRAN version is outdated, only
  install from GitHub
